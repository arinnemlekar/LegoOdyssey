This folder contains source code for our PIR-triggered camera project using the Seeed Studio XIAO ESP32S3 Sense. The project detects motion, captures photos, and saves them to a microSD card. An LED confirms successful capture, and a five-second pause separates capture attempts. Additional sketches explore accessing saved photos from a laptop through USB Mass Storage.

As the project develops, we may add code to support additional sensors and expand the system’s capabilities.
