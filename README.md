⚠️ Important
Always start new work from the latest Master Program.

Do not use an old copy of the Master Program saved on your computer.

The Master Program may be updated as we improve our robot code. Starting from the latest version makes sure everyone is using the same foundation.

When starting a new mission, run, strategy, or experiment:

Pull the latest files from GitHub.

Make a new copy of the latest Master Program.

Rename the copy using the naming convention below.

Open your new file in Pybricks.

Start coding and testing.

Do not directly modify the Master Program.

📝 File Naming Convention
Every program should follow this format:

FirstName(Partner)_YYYYMMDD_FileDescription.py

Individual work
Mukund_20260927_Mission01.py
Andy_20260927_Mission02.py
Rahil_20260927_Mission03.py

Partner work
If two teammates are working together, include both names:

MukundAndy_20260927_Mission01.py
ArinRahil_20260927_Mission03.py

For three teammates:

MukundAndySid_20260927_Mission02.py

Different strategies
If multiple people are trying different approaches to the same mission, each person should have their own file:

Mukund_20260927_Mission01.py
Andy_20260927_Mission01.py
Rahil_20260927_Mission01.py

You can also describe the strategy:

Mukund_20260927_Mission01_LeftApproach.py
Andy_20260927_Mission01_RightApproach.py

The filename should make it clear:

Who worked on it → When → What it is

🚫 Don't Overwrite Someone Else's Work
If someone has already uploaded a program, don't modify their file and save it under their name.

Make your own copy instead.

For example, if Andy has:

Andy_20260927_Mission03.py

and Mukund wants to try a different approach, Mukund should create:

Mukund_20260927_Mission03.py

This keeps everyone's work available for the team to review and compare.

💻 Git Workflow
You don't need to learn everything about Git.

For this project, we mainly need a few commands.

First time only: Clone the repository
git clone https://github.com/arinnemlekar/LegoOdyssey.git

Then enter the repository:

cd LegoOdyssey

Before starting work
Always get the latest version:

git pull

Check your changes
git status

Add your file
git add <filename>

For example:

git add Mukund_20260927_Mission01.py

Or add all changes:

git add .

Save your changes with a commit
git commit -m "Add Mission 1 program"

Try to make the message describe what you changed.

Examples:

git commit -m "Test new attachment"

git commit -m "Improve Mission 3 alignment"

Upload your work
git push

🏁 End of Every Robotics Session
Before leaving a robotics session:

Save your latest code.

Export your program from Pybricks.

Make sure the filename follows our naming convention.

Upload your work to GitHub.

Commit your changes.

Push your changes.

This gives the entire team a backup of your work.
